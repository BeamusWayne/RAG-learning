01 / 入门

认识 Milvus

Milvus 是全球最流行的开源向量数据库，专为 AI 应用设计。它能存储和搜索数十亿向量，让你轻松实现语义搜索、推荐系统、RAG 等功能。

⚡
超高速检索
十亿向量毫秒级响应，支持 GPU 加速
🔄
灵活扩展
从小 demo 到生产集群，无缝扩展
🔗
多模态支持
文本、图像、音频、视频向量统一存储
🛠️
丰富接口
Python、Java、Go、RESTful 多语言SDK
💡
什么时候用 Milvus？
当你需要搜索"相似的内容"时，比如：找相似图片、搜相似商品、做语义搜索、实现 RAG（检索增强生成）、推荐系统等。

Milvus 应用场景

场景说明效果
RAG结合大语言模型，实现知识增强回答准确率提升 40%+
语义搜索理解查询意图，不只是关键词匹配召回率提升 60%+
相似图片搜索以图搜图，找相似产品/素材毫秒级响应
推荐系统基于用户行为，推荐相似内容点击率提升 30%
异常检测找出与正常模式差异大的数据实时预警
02 / 入门

快速安装

两种安装方式：轻量版适合学习和开发，生产环境用 Docker 部署。

推荐 Milvus Lite（学习/开发）

轻量级嵌入版本，直接安装到 Python 项目中，适合本地开发和测试。

bash
# 安装 pymilvus（包含 Milvus Lite） pip install -U pymilvus # 可选：安装 embedding 模型支持 pip install "pymilvus[model]"
✓
Milvus Lite 会自动创建本地数据库文件，无需额外配置！
生产 Docker 部署（生产环境）

使用 Docker 一键启动完整 Milvus 服务，支持高并发和大规模数据。

bash
# 下载安装脚本 curl -sfL https://raw.githubusercontent.com/milvus-io/milvus/master/scripts/standalone_embed.sh -o standalone_embed.sh # 启动 Milvus bash standalone_embed.sh start # 查看状态 docker ps | grep milvus
⚠️
Docker 方式需要至少 4GB 内存，确保你的机器配置足够。

验证安装

python
# 验证 Milvus 连接 from pymilvus import MilvusClient # 尝试连接（Lite 版本会创建本地文件） client = MilvusClient("test.db") print("✅ Milvus 连接成功！")

03 / 入门

第一个应用：语义搜索

只需 5 行代码，你就能实现一个语义搜索引擎。让我们从一个完整示例开始。

python
""" 完整示例：5 分钟实现语义搜索 """ from pymilvus import MilvusClient, model # 1. 初始化客户端（会自动创建本地数据库） client = MilvusClient("semantic_search.db") # 2. 创建集合（存储向量和文本） if client.has_collection("articles"): client.drop_collection("articles") client.create_collection( collection_name="articles", dimension=768 # 向量维度，与 embedding 模型匹配 ) # 3. 准备数据（文档 + 向量） docs = [ "人工智能起源于 1956 年的达特茅斯会议", "图灵是 AI 领域的先驱，被称为人工智能之父", "深度学习在 2012 年的 ImageNet 竞赛中突破性胜出", "Transformer 架构革新了自然语言处理", "ChatGPT 展示了对话式 AI 的巨大潜力" ] embedding_fn = model.DefaultEmbeddingFunction() vectors = embedding_fn.encode_documents(docs) data = [{"id": i, "vector": vectors[i], "text": docs[i]} for i in range(len(docs))] # 4. 插入数据 client.insert(collection_name="articles", data=data) print(f"✅ 插入 {len(data)} 条数据") # 5. 语义搜索 query = "谁被称为人工智能之父？" query_vector = embedding_fn.encode_queries([query]) results = client.search( collection_name="articles", data=query_vector, limit=2, # 返回最相似的 2 条 output_fields=["text"] ) print(f"\n🔍 搜索: {query}") print("📄 结果:") for result in results[0]: print(f" - {result['entity']['text']} (相似度: {result['distance']:.3f})")
✅ 插入 5 条数据 🔍 搜索: 谁被称为人工智能之父？ 📄 结果: - 图灵是 AI 领域的先驱，被称为人工智能之父 (相似度: 0.852) - 人工智能起源于 1956 年的达特茅斯会议 (相似度: 0.681)
🧠
发生了什么？
1. 文本被转换成 768 维向量
2. 向量存储到 Milvus 集合中
3. 搜索时，查询文本也转换成向量
4. Milvus 找到与查询向量最相似的向量
04 / 核心概念

Collection 集合

Collection（集合）是 Milvus 中存储数据的基本单位，类似传统数据库中的表。每个 Collection 包含多条记录（Entity），每条记录有多个字段（Field）。

Collection 数据结构示意
Field
id (主键)
Field
vector (向量)
Field
text (文本)
Field
category (分类)
Entity 0
Entity 1
Entity 2
...

创建 Collection

python
# 方式 1：简化创建（最常用） client.create_collection( collection_name="my_collection", dimension=768 # 向量维度 ) # 方式 2：完整配置（推荐用于生产） from pymilvus import CollectionSchema, FieldType, DataType fields = [ FieldType(name="id", dtype=DataType.INT64, is_primary=True), FieldType(name="vector", dtype=DataType.FLOAT_VECTOR, dim=768), FieldType(name="text", dtype=DataType.VARCHAR, max_length=10000), FieldType(name="category", dtype=DataType.VARCHAR, max_length=50) ] schema = CollectionSchema(fields=fields, description="我的集合") client.create_collection( collection_name="my_collection_full", schema=schema, metric_type="COSINE" # 余弦相似度 )

集合操作

python
# 查看所有集合 collections = client.list_collections() # 检查集合是否存在 exists = client.has_collection("my_collection") # 查看集合详情 info = client.describe_collection("my_collection") # 删除集合 client.drop_collection("my_collection") # 加载集合到内存（搜索前必须） client.load_collection("my_collection") # 释放集合（节省内存） client.release_collection("my_collection")
05 / 核心概念

Schema 结构设计

Schema 定义了 Collection 的数据结构，包括字段类型、主键设置、索引策略等。好的 Schema 设计能显著提升查询性能。

数据类型说明示例
INT6464位整数主键1, 2, 3, ...
VARCHAR字符串，可设最大长度"hello", "category"
FLOAT_VECTOR浮点向量，必须指定维度[0.1, 0.5, ...] (768维)
BOOL布尔值true, false
FLOAT/DOUBLE浮点数1.5, 3.14

完整 Schema 示例

python
from pymilvus import CollectionSchema, FieldType, DataType # 定义字段 fields = [ # 主键字段 - 唯一标识每条记录 FieldType(name="id", dtype=DataType.INT64, is_primary=True, auto_id=True), # 向量字段 - 用于相似度搜索（必须建索引） FieldType(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=1536), # 文本字段 - 用于存储原始文本 FieldType(name="content", dtype=DataType.VARCHAR, max_length=5000), # 元数据字段 - 用于过滤搜索 FieldType(name="category", dtype=DataType.VARCHAR, max_length=100), FieldType(name="created_at", dtype=DataType.INT64), # Unix 时间戳 FieldType(name="views", dtype=DataType.INT64), ] # 创建 Schema schema = CollectionSchema( fields=fields, description="RAG 知识库集合", enable_dynamic_field=True # 允许插入未定义的字段 ) # 创建 Collection client.create_collection( collection_name="knowledge_base", schema=schema, metric_type="COSINE", # 余弦相似度 index_type="AUTOINDEX" # 自动选择最优索引 )
💡
主键 auto_id=True
设置 auto_id=True 后，插入数据时不需要提供主键，Milvus 会自动生成。这是最推荐的方式。
06 / 核心概念

索引类型

索引是加速向量搜索的关键。不同的索引类型适用于不同的场景和数据规模。

索引类型适用场景内存占用搜索速度精度
FLAT小数据集，精确搜索高慢100%
IVF_FLAT中等规模，平衡型中中高
HNSW大规模，高性能高快高
DISKANN十亿级，超大规模低快中高
AUTOINDEX自动优化，省心自动自动自动

创建索引

python
# 方式 1：自动索引（推荐，最省心） client.create_index( collection_name="my_collection", field_name="vector", index_type="AUTOINDEX", metric_type="COSINE" ) # 方式 2：HNSW 索引（高性能，适合大规模） client.create_index( collection_name="my_collection", field_name="vector", index_type="HNSW", params={"M": 16, "efConstruction": 200}, metric_type="COSINE" ) # 方式 3：IVF_FLAT 索引（平衡之选） client.create_index( collection_name="my_collection", field_name="vector", index_type="IVF_FLAT", params={"nlist": 1024}, metric_type="COSINE" )
⚠️
索引参数说明
M: HNSW 邻居数，更高 = 更精确但更占内存
efConstruction: 构建时的搜索深度
nlist: IVF 聚类中心数
07 / 数据操作

插入数据

数据以 Entity（实体）形式插入集合。每个 Entity 包含所有字段定义的值。

基本插入

python
# 准备数据（每条是一个 dict） data = [ {"id": 1, "vector": [0.1, 0.2, ...], "text": "第一个文档"}, {"id": 2, "vector": [0.3, 0.4, ...], "text": "第二个文档"}, ] # 插入数据 result = client.insert( collection_name="my_collection", data=data ) print(f"插入数量: {result['insert_count']}") print(f"生成的 ID: {result['ids']}")

批量插入 + 自动 ID

python
# 使用 auto_id=True 时，不需要提供 id data = [ {"vector": [0.1, 0.2, ...], "text": "文档 A", "category": "科技"}, {"vector": [0.3, 0.4, ...], "text": "文档 B", "category": "科技"}, ] result = client.insert(collection_name="my_collection", data=data) print(f"自动生成的 ID: {result['ids']}") # [4, 5, 6]

Upsert（插入或更新）

python
# 如果 id 存在则更新，不存在则插入 data = [ {"id": 1, "vector": [0.9, 0.8, ...], "text": "更新后的文档"}, ] client.upsert(collection_name="my_collection", data=data)

删除数据

python
# 按 ID 删除 client.delete(collection_name="my_collection", ids=[1, 2, 3]) # 按条件删除 client.delete(collection_name="my_collection", filter="category == '科技'")
08 / 数据操作

向量搜索

向量搜索是 Milvus 的核心功能。它找到与查询向量最相似的向量，返回对应的实体。

基础搜索

python
# 搜索最相似的 5 条 query_vector = embedding_fn.encode_queries(["查询文本"])[0] results = client.search( collection_name="my_collection", data=[query_vector], limit=5, output_fields=["text", "category"] # 返回哪些字段 ) # 处理结果 for result in results[0]: print(f"ID: {result['id']}") print(f"相似度: {result['distance']}") print(f"文本: {result['entity']['text']}")

批量搜索

python
# 同时搜索多个查询向量 query_vectors = embedding_fn.encode_queries(["第一个查询", "第二个查询"]) results = client.search( collection_name="my_collection", data=query_vectors, limit=3 ) # results[0] 是第一个查询的结果，results[1] 是第二个

范围搜索

python
# 搜索相似度 >= 0.8 的结果 results = client.search( collection_name="my_collection", data=[query_vector], limit=10, search_params={"radius": 0.8, "range_filter": 1.0} )
📊
搜索结果解读
distance: 相似度距离，值越小表示越相似（COSINE）
id: 匹配的实体主键
entity: 返回的字段值
09 / 数据操作

元数据过滤

在向量搜索的同时，可以根据元数据字段过滤结果，实现更精准的检索。

过滤表达式

操作符说明示例
==等于category == 'tech'
!=不等于status != 'deleted'
>大于price > 100
<小于views < 1000
in在集合中category in ['tech', 'science']
and且(category == 'tech') and (views > 100)
or或(category == 'tech') or (category == 'science')

带过滤的搜索

python
# 只搜索分类为"科技"的文档 results = client.search( collection_name="my_collection", data=[query_vector], filter="category == '科技'", limit=5, output_fields=["text", "category", "created_at"] ) # 组合过滤：科技分类 且 浏览量大于 100 results = client.search( collection_name="my_collection", data=[query_vector], filter="(category == '科技') and (views > 100)", limit=5 ) # 多值过滤 results = client.search( collection_name="my_collection", data=[query_vector], filter="category in ['科技', '经济', '文化']", limit=10 )

标量查询（不带向量搜索）

python
# 查询所有符合条件的记录 results = client.query( collection_name="my_collection", filter="category == '科技' and views > 100", output_fields=["id", "text", "category", "views"] ) # 按 ID 查询 results = client.query( collection_name="my_collection", ids=[1, 2, 3], output_fields=["text", "category"] )

架构解析

Milvus 采用云原生设计，四层架构相互独立，支持水平扩展。

接入层 (Access Layer)

轻量级无状态代理，负责验证客户端请求、聚合和后处理结果。使用负载均衡统一提供服务入口。

协调器 (Coordinator)

集群大脑，负责维护拓扑结构、调度任务、保证一致性。
• Root Coord: 处理 DDL/DCL 请求
• Query Coord: 管理查询节点和负载均衡
• Data Coord: 管理数据节点和数据视图

工作节点 (Worker Nodes)

无状态执行器，遵循协调器指令：
• Query Node: 搜索历史数据
• Data Node: 压缩和建索引
• Streaming Node: 处理实时写入

存储层 (Storage)

持久化数据：
• etcd: 元数据（schema、索引配置）
• 对象存储: 索引文件、日志快照
• WAL: 写入前置日志，保证一致性
